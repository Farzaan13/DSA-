# [Count Distinct in Array](https://www.geeksforgeeks.org/problems/find-distinct-elements--130928/1)
## Easy
Given an integer array arr[], return the count of all the distinct elements in an arrayExamples:Input: arr[] = [2, 2, 3, 2]
Output: 2Explanation: Distinct elements are {2, 3}Input: arr[] = [12, 1, 14, 3, 16]
Output: 5Explanation: Distinct elements are {12, 1, 14, 3, 16}Input: arr[] = [1, 1, 1, 1]Output: 1Explanation: Only one distinct element {1}
